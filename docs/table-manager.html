配分条件

総対局数
6名 × 30半荘 ÷ 3名 = 60半荘。
完全均等
20通りの3人組が各3回。各人30半荘、15通りのペアが各12回同卓。
序盤に偏りがある場合
終了済みの対局は変更せず、各人30半荘を必須条件として残りを配分。ペア同卓の最大偏差、ペア偏差の合計、3人組の偏差の順に小さくする調整案を計算します。
推奨の意味
残り全体の配分案に含まれる卓から、消化数・同卓回数の少ない組を先に表示。唯一の正解ではなく、以後の実績で再計算されます。
未取得・判別不能の対局
成績詳細が足りない、または対象6名以外が含まれる場合は件数を表示し、推奨を保留します。座順・親回数はこの配分の対象外です。
