# BGM 仕様（追補）

現行仕様書 8.1 節「効果音」に対する追補。本書は BGM のみを扱う。
効果音・鼓動・呪いノイズの既存仕様は変更しない。

---

## 0. 最優先の原則

### 0-1. BGM は効果音の情報を潰してはならない

本作の効果音は**演出ではなく情報**である。足音、肩の接触、振り返り、飲水、
壁越しのこもり——これらが「誰がどこで何をしたか」を伝える唯一の手段になっている。

**BGM がこの帯域を覆った瞬間、ゲームの根幹が壊れる。**
したがって BGM は「常時鳴る曲」ではなく、**効果音の隙間に置く薄い層**として設計する。

### 0-2. BGM は敵の存在を漏らしてはならない

**これが本作で最も重要な BGM の制約。**

一般的なホラーゲームは「敵が近づくと音楽が緊張する」を使うが、
本作でそれをやると**14.1 節の匿名出現・秘匿設計が BGM 経由で全部崩れる。**
プレイヤーは 2 試合で「音楽が変わった＝近くに敵がいる」と学習する。

**したがって：**

- 敵の距離・存在・数によって BGM を変化させない
- 変化させてよいのは、**本人が既に知っている情報だけ**
  （自分の呪い状態、自分の水分、試合の残り時間、保管済みの札数）
- 呪い層は**呪われている本人にだけ**鳴らす。他人に「誰が呪われているか」を音で教えない
  （8 節の鼓動音と同じ扱い）

### 0-3. 無音を資源として扱う

探索中の基本状態は**ほぼ無音**にする。音楽が鳴っていない時間を長く取るほど、
鳴り始めた瞬間の効果が上がる。全編に曲を敷かない。

## 1. 構成：ホリゾンタル・レイヤリング

**曲を切り替えるのではなく、同じ長さ・同じテンポの層を重ね、ゲインだけを動かす。**
切り替え方式（別の曲へ遷移）は同期が破綻しやすいので採用しない。

全層を**同一の小節長でループ**させ、常に再生し続けたままゲインで出し入れする。

| 層 | 鳴る条件 | 聞こえる相手 | 既定ゲイン |
|---|---|---|---:|
| **L0 環境層** | 常時 | 全員 | -32 dBFS 前後 |
| **L1 探索層** | 試合中、L2 以上が鳴っていないとき | 全員 | -26 dBFS |
| **L2 呪い層（1 段階）** | `cursed` かつ `hits` 1 | **本人のみ** | -20 dBFS |
| **L3 追跡層（2 段階）** | `cursed` かつ `hits` 2 | **本人のみ** | -16 dBFS |
| **L4 終盤層** | 残り時間 30% 以下、または保管札が必要数の 80% 以上 | 全員 | -22 dBFS |
| **L5 顔演出層** | 掴まれ演出中（1/2/3 回目で別素材） | **本人のみ** | -10 dBFS |
| **L6 水切れ層** | 水分 0% の猶予 60 秒中 | **本人のみ** | -20 dBFS |

### 各層の内容案

- **L0 環境層** — 音楽というより空間。40〜120Hz の持続低音、遠い水の反響、金属の軋み。
  これは実質 8.1 節の「室内環境音」の延長で、既存素材と統合してよい
- **L1 探索層** — 音程を持たない素材中心。撥弦の残響、逆再生したシンバル、不定期な単音。
  拍を感じさせない。「曲」と認識させないことが目的
- **L2 呪い層** — 低弦のトレモロ。既存の鼓動 SE（拍間隔 1.4 秒）と**テンポを合わせない**。
  合わせると鼓動が音楽に溶けて情報として読めなくなる
- **L3 追跡層** — ここで初めて拍が入る。鼓動 0.7 秒間隔に対し、
  音楽は意図的にずらす（例：付点や 3 連）。焦燥感が出て、かつ鼓動が埋もれない
- **L4 終盤層** — 唯一、希望側の色を持つ層。上行する持続音。
  「あと少し」を伝える。恐怖一辺倒にしないための層
- **L5 顔演出層** — 1 回目 7 秒／2 回目 8 秒／3 回目 9.8 秒に**尺を合わせた専用素材**。
  ループさせない。3 回目は敗北ジングルへ直結する
- **L6 水切れ層** — 高域の細い持続音＋不規則な揺れ。赤点滅（2.4 秒周期）と
  **同期させない**（同期すると演出が安っぽくなり、点滅への注意も薄れる）

### 単発（層ではない）

| 素材 | 尺 | 備考 |
|---|---:|---|
| 試合開始 | 3〜4 秒 | タイトルからの遷移。L0/L1 へ自然に落ちる |
| 勝利 | 8〜12 秒 | 全員共通 |
| 敗北（チーム全滅・時間切れ） | 8〜12 秒 | 全員共通 |
| 個人脱落（3 回目） | L5 の 3 回目から連結 | **本人のみ。** 8.1 節「敗北の音は本人の致死演出 9.8 秒より先に割り込ませない」を踏襲 |
| ロビー／タイトル | ループ | 唯一、普通に「曲」でよい場所 |

## 2. 周波数の住み分け（実務上これが最重要）

効果音と衝突しないよう、**BGM 側に帯域制限をかける。**

| 帯域 | 主な用途 | BGM の扱い |
|---|---|---|
| 20〜80 Hz | 鼓動、天井落下の衝撃、暗転 | L0 の持続低音のみ。他層は**ハイパス** |
| 80〜250 Hz | 環境の厚み | BGM の主戦場 |
| **250 Hz〜2 kHz** | **足音・肩の接触・振り返り・飲水・水音・声** | **BGM は原則ここを空ける。** どうしても必要なら -12 dB 以下 |
| 2〜8 kHz | 警報、ソナー、金属、紙 | BGM は控えめ。警報と competing しないこと |
| 8 kHz 以上 | 空気感 | 自由 |

**全 BGM 素材に 250Hz〜2kHz のディップ（-6〜-9dB、Q 広め）を最初から焼き込む**のが、
実装で最も確実。ミキサー側の動的 EQ に頼るより破綻しない。

## 3. ダッキング（サイドチェイン）

身体動作音が鳴った瞬間、BGM 全層を一時的に下げる。

| 項目 | 値 |
|---|---|
| トリガ | 8.1 節の「身体動作音」カテゴリ（足音を除く）と警報・ソナー |
| 減衰量 | -6 dB |
| アタック | 30 ms |
| ホールド | 150 ms |
| リリース | 400 ms |
| 適用先 | L0〜L4、L6（L5 顔演出層は対象外） |

**足音はトリガに含めない**（常時鳴るのでダッキングが常時かかってしまう）。
代わりに足音は 2 節の帯域分離で確保する。

顔演出中（L5）は、8.1 節の既存仕様どおり環境音と鼓動を下げる処理に BGM も含める。

## 4. 遷移

| 遷移 | 時間 | 備考 |
|---|---:|---|
| 通常の層の増減（L1↔L2↔L3↔L4） | 1.2 秒クロスフェード | 等パワー |
| **L5 顔演出層への突入** | **即時（0 秒）** | ショックの一部。ここだけフェードしない |
| L5 からの復帰（救助） | 0.6 秒 | 8.1 節「救助で中断する」と同じ扱い |
| 試合終了 | 0.4 秒で全層停止 → 単発へ | |
| 呪い解除 | 1.2 秒 | 解除が音で分かるのは正しい（本人は既に知っている） |

**層のループ位相は全層で共有する。**個別に再生開始すると、
ゲインを上げた瞬間に小節がずれて違和感が出る。
試合開始時に全層を同時に `start()` し、以後はゲインのみ操作する。

## 5. 音量とユーザー設定

現行の「効果音量（初期 72%）」に加えて：

| 設定 | 初期値 | 保存 |
|---|---:|---|
| マスター音量 | 100% | 端末に保存 |
| 効果音量 | 72%（現行のまま） | 端末に保存 |
| **BGM 音量** | **45%** | 端末に保存 |

**BGM の初期値を効果音より明確に低くする。**
BGM を 0% にしても遊べること、効果音を 0% にすると遊べないことを、
音量バランスで示す。

ミュート・退出・再接続中・非表示タブの扱いは 8.1 節の効果音と同一にする。

## 6. 形式とデータ量 — 現行の効果音にも関わる重要事項

### 6-1. BGM は非圧縮にしない

| 項目 | 指定 |
|---|---|
| 形式 | **Opus**（`.webm` または `.ogg`）。フォールバックに AAC(`.m4a`) |
| ビットレート | 96〜128 kbps |
| サンプルレート | 48 kHz |
| 全 BGM 合計 | **2 MB 以下**を目標 |

### 6-2. 現行の効果音 8.0 MB（WAV）も圧縮を強く推奨

現行仕様 8.1 節：「48kHz・16bit PCM、実行時の音素材は計約 8.0MB」。

**これはモバイル回線での初回読み込みに対して重い。**
Opus 96kbps に変換すれば**おおむね 1/10 前後**になる。

- 短い衝撃音（足音・接触）は、圧縮による劣化がほぼ問題にならない
- どうしても非圧縮を維持したい素材があるなら、**その素材だけ WAV に残す**
- 3 節のダッキングやピーク制限は、デコード後の Web Audio 上で行うので圧縮の影響を受けない

**BGM を足すと総量が増えるため、この圧縮は BGM 導入と同時に行うのが合理的。**

### 6-3. 読み込みの段階化

| 段階 | 読み込む |
|---|---|
| タイトル表示時 | ロビー曲、UI 音のみ |
| 試合開始時 | L0・L1・効果音の主要セット |
| 試合開始後（背景で） | L2〜L6、勝敗ジングル、低頻度の効果音 |

L5（顔演出層）が未読込のまま掴まれた場合は**無音で進行させ、演出を止めない。**
音の読み込み失敗がゲーム進行を阻害しない設計にする。

## 7. ループ処理

- **シームレスループ必須。**ループ境界のクリックノイズ対策として、
  境界をゼロクロッシングに合わせるか、`AudioBufferSourceNode.loopStart/loopEnd` を
  サンプル単位で指定する
- Opus は先頭に埋め込みディレイ（pre-skip）を持つため、
  **エンコード後にループ点がずれていないか実機で確認すること。**
  ずれる場合は WAV でループ点を確定してから変換し、`loopStart` を補正する
- 各層は**同一の尺**にする（例：全層 32 秒）。異なる尺だと位相が合わなくなる

## 8. 実装の配置案

現行の `src/audio.ts` / `src/soundscape.ts` / `src/sound-director.ts` の構成に対し：

| ファイル | 役割 |
|---|---|
| `src/music.ts`（新規） | 層の生成、ゲイン制御、遷移、ループ位相の共有 |
| `src/sound-director.ts`（改修） | 層の目標ゲインを決める。**本人／第三者の分配ルールを効果音と共用する** |
| `src/audio.ts`（改修） | マスター／効果音／BGM の 3 系統ゲインノード。ダッキングのサイドチェイン |
| `public/audio/music/` | BGM 素材 |
| `MUSIC_DESIGN.md` | 素材一覧・出典・尺・ループ点・帯域処理の記録（`SOUND_DESIGN.md` に倣う） |

`sound.html` に BGM 層の個別試聴と、層を重ねた状態の確認を追加する。
`review.html` の各シーンで BGM 込みの再生を確認できるようにする。

## 9. 受け入れ確認シナリオ（22 節への追加）

| シナリオ | 期待する結果 |
|---|---|
| 敵が背後 3m まで接近（未発覚） | **BGM が一切変化しない** |
| 敵が視界に入る／出現する | **BGM が一切変化しない**。匿名通知音のみ |
| 呪われる（1 回目） | 本人だけ L2 が 1.2 秒で立ち上がる。**第三者の BGM は変化しない** |
| 呪いが解除される | 本人だけ L2/L3 が 1.2 秒で下がる |
| 掴まれ演出に入る | L5 が即時、他層が下がる。本人のみ |
| 演出中に救助される | L5 が 0.6 秒で停止し、残りを後から鳴らさない |
| 足音・肩の接触が鳴る | BGM が -6 dB へダッキングし、400ms で戻る |
| BGM 音量 0% | 効果音だけで通常どおり遊べる |
| 効果音量 0%・BGM 100% | 足音や接触が聞こえず**遊びづらい**ことを確認（音の役割分担の検証） |
| 非表示タブ・ミュート・退出 | BGM も即時停止。復帰時に溜まった音を鳴らさない |
| L5 素材の読み込み失敗 | 演出は無音で正常に進行し、進行不能にならない |
| 試合を 12 分通す | ループ境界でクリックノイズが出ない |
