# 開発コストと、1 人で作れるか

## 0. 結論

- **PC で友人とテストプレイできる状態までの現金支出は、実質ゼロ。**
- **1 人で作れるか＝「全部作れるか」を今決める必要はない。**
  この企画が面白いかどうかの答えは、**1 か月・0 円**で出る。そこまでを 1 人でやるのは確実に可能。
- 製品版（スマホ販売）まで 1 人で行くのは可能だが、**現実的には 1.5〜3 年**。
  同ジャンルに 1 人での成功例がある（4 章）。

## 3. ハードウェア

## 4. 1 人で作れるか

### 4-1. この企画は、意図せず「1 人向け」に最適化されている

これまでの決定が、偶然すべてソロ開発に有利な方向へ積み上がっている。

| 決定 | ソロにとっての意味 |
| --- | --- |
| 敵は AI（PvE） | **1 人でテストできる。**PvP なら毎回 5〜6 人集める必要があった |
| キャラは 2D スプライト | リグ・スキニング・アニメーションブレンド・IK が**全部不要** |
| 常時走りモーション | 移動アニメーションが**1 本だけ** |
| 4 方向 | スプライト枚数が半減（約 410 枚） |
| ボディ 1 体を全員で共有＋レイヤー分離 | キャラ制作が実質 1 体分 |
| 3D から自動レンダリング | 魚の追加が**自動化できる** |
| 1 試合 10〜14 分・マップ 1 つで MVP | 物量が小さい |
| 操作が 5 つだけ | UI とチュートリアルが軽い |

**普通、個人開発でマルチプレイ 3D ホラーは無謀**だが、この設計はその難所を削り続けている。

### 4-2. それでもソロで詰まる場所（正直に）

| 難所 | 深刻度 | 備考 |
| --- | --- | --- |
| **ネットワーク実装** | **最大** | 個人開発が死ぬ場所。同期ズレ、遅延、再接続の泥沼。見積もりの 2〜3 倍かかると考えること |
| **ダンジョンのレベルデザインと照明** | 大 | モジュラー素材で楽はできるが、「見通しの悪さの設計」は技能 |
| モバイル移植 | 中 | タッチ UI、低スペック対応、ストア審査。それぞれ別プロジェクト級 |
| アート物量 | 中 | 3D レンダリング方式なら軽い。**手描きに逃げると破綻する** |
| **十数か月の継続と、スコープ管理** | **最大級** | 技術的難所より、これで終わるプロジェクトの方が多い |

### 4-3. 前例

**Lethal Company は 1 人（Zeekerss）で作られた、Unity 製のマルチプレイ協力ホラー。**
本企画とほぼ同じ条件で、商業的に大成功している。

他に Among Us（3 人）、Devour（少人数）、Gorilla Tag（少人数）など、
このジャンルは小規模チームの成功例が多い。**人数よりも、対象ジャンルとの相性の問題。**

ただし前提として、Zeekerss には長年のゲーム制作経験があった。
**頭数より経験値が効く領域**であることは正直に押さえておくこと。

### 4-4. 期間の目安（1 人の場合）

| 到達点 | 経験者 | Unity 未経験から |
| --- | --- | --- |
| 段階 1（核の検証・PC・1 人） | 2〜4 週間 | 1.5〜3 か月 |
| 段階 2（ネットワークで友人と遊べる） | ＋1〜2 か月 | ＋3〜5 か月 |
| 段階 3（擬態と AI が入り、企画通りになる） | ＋2〜3 か月 | ＋4〜6 か月 |
| スマホで販売できる製品版 | 1〜2 年 | 2〜3 年 |

## 5. 助けを入れるなら、どこか

1 人でも始められるが、途中で誰かに入ってもらうなら、効果が高い順に：

1. **レベルデザイン／照明**——本作は「見通しの悪さ」がゲーム性そのもの。ここの質が体験を直接決める
2. **ネットワーク**——最も泥沼化しやすく、経験の有無で差が最も大きい
3. **サウンド**——本作は音が体験の半分（足音、呼吸、悲鳴、声の録音再生）。効果が大きいわりに外注しやすい
4. アート——この設計では最も安く済むので、優先度は低い

---

## 6. 推奨する進め方

**「全部 1 人で作れるか」を今決めない。**

決めるべきは、**「1 か月と 0 円を使って、この企画が面白いかを確かめるか」**だけ。

段階 1（PC・1 人・箱と円柱・棒人間のスプライト・追ってくるだけの AI）を作り、
**「後ろを取り合う数秒が緊張するか」**を自分と友人 2〜3 人で確かめる。

- 面白い → そこから体制も予算も考えればよい。判断材料が手に入っている
- 面白くない → 失ったのは 1 か月だけ。しかもカメラ・速度・予備動作時間を変えて再挑戦できる

**この企画で最も安く買える情報が、最も重要な情報**という良い状況にある。
