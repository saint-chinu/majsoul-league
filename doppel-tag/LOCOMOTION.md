# 移動と「止まる」の仕様 — 歩行への変更と、見られると止まる AI

FUN_CORE.md の核モードを前提にした、移動速度と AI の停止挙動の仕様。

---

## 1. 歩行を基本にする

### 1-1. 何が変わるか

| 項目 | 現行 | 変更後 |
|---|---|---|
| 基本速度 | 4.4 m/s（走り） | **1.6 m/s（速歩き）** |
| 後方確認中 | 60% | 60%（約 1.0 m/s） |
| アニメーション | 常時走り | **常時歩き。静止していても脚は動く**（規則は維持） |
| 走り | なし | **状態で自動発動。ボタンはない**（1-3） |

**「アニメーションが止まらない」規則はそのまま。**歩きに変えるだけ。
この規則が AI の擬態を動作レベルで成立させている（AI_DESIGN.md 3-1）ので、
歩き／静止／待機の区別を作ってはいけない。

### 1-2. 歩行が買うもの

1. **予感の時間が伸びる。**接近に 3 倍かかる。恐怖の本体は「来るかもしれない時間」なので、
   これは直接効く
2. **8 方向スプライトが読める。**4.4 m/s では向きの帯が一瞬で切り替わり、
   「あの人の背中はこちらを向いているか」を判断する前に通り過ぎる。1.6 m/s なら読める
3. **通信遅延の影響が 1/3 になる。**RTT 300ms の間に動く距離が 1.3m → 0.5m。
   REVIEW P1-8（掴みボタンの表示と判定のずれ）の実害が大幅に減る
4. **マップが広く感じる。**94m 四方を 21 秒で横切れた空間が、60 秒かかる空間になる。
   作り直さずに「広い廃施設」になる
5. **足音が情報になる。**歩きの足音は間隔が長く、数えられ、方向が取れる
6. **走りに意味が生まれる**（1-3）。全員が常に走っている世界では、走りは何も伝えない

### 1-3. 走りは「状態」であって「操作」ではない

走りのボタンを足すと操作が 5 つになり、スタミナという新しいゲージが要る。
代わりに、**走りを感情の状態として自動発動させる。**

| 誰が | いつ走るか | 速度 |
|---|---|---|
| 呪われた本人 | 呪い状態の間、常に | 3.2 m/s（2.0 倍） |
| ドッペル | 狩り（襲撃・追跡）の間 | 3.4 m/s（走りの 1.05 倍。現行比率を維持） |
| **近くの仲間** | 走っている呪われた人から **10m 以内**にいる間 | 3.2 m/s |
| **近くのドッペル**（潜伏中） | 同上。**仲間と同じ条件で走る** | 3.2 m/s |

**これで起きること：**

- 走りが**目に見える異変の信号**になる。「なぜマグロが走っている？」
- パニックが伝染する。1 人が呪われると、周囲が一斉に走り出す。**波が広がる絵**ができる
- 救助が成立する。呪われた人の近くの仲間は自動で同速になる（現行の救援ブースト 1.15 倍を置き換える）
- 潜伏中のドッペルも同じ条件で走るので、**走っている集団の中に紛れたまま**
- 現行の走りアニメーション 2,304 コマは無駄にならない。**パニックの作画になる。**
  常時走りでは対比がなかったが、歩きの中の走りは強い対比になる

走りに切り替わる瞬間は加速なし（即座に 3.2 m/s）。歩きに戻る瞬間も即座。
8 方向スプライトの世界では、加減速のない「デジタルな」移動の方が自然で、
かつ後述の「ピタッと止まる」との整合が取れる。

### 1-4. 旋回速度

2.8 rad/s は走り基準の値。歩きでは **2.2 rad/s** から試す。
真後ろを向くのに約 1.4 秒。速すぎると背後を取る緊張が消え、遅すぎると操作がもたつく。
CONFIG で調整。

## 2. 見られると止まる

### 2-1. 基本

**潜伏・接近中のドッペルは、生存プレイヤーの視界に入った瞬間、その場で止まる。**

- 減速しない。**即座に速度 0**。人間は減速して止まるが、これは止まる
- **脚は動き続ける。**「アニメーションが止まらない」規則のとおり。
  止まって足踏みしている仲間と、画面上は完全に同じ
- 視界から外れると、また近づく
- 足音は実移動に紐づいているので、**止まった瞬間に足音が消える。**
  「振り返ったら、後ろの足音が止まった」——音だけでも成立する恐怖

### 2-2. 「視界」の定義

| 条件 | 内容 |
|---|---|
| 角度 | 観測者の**カメラの前方 ±50 度**（追従カメラの画角にほぼ一致）。後方確認中はその後方ビューが「前方」 |
| 距離 | 制限なし（暗闇では 3m までしか見えないが、判定は幾何で行う。見えていなくても止まる方が安全側） |
| 遮蔽 | 壁越しは視界に含めない |
| 誰の視界か | **生存している人間プレイヤー全員、および仲間 AI**（2-6） |

観戦者のカメラは含めない（観戦者に敵を止める力を与えない）。

### 2-3. 見られていない間の接近速度

**歩きの 1.3 倍（約 2.1 m/s）。**

振り返るたびに「思ったより近い」が起きる。
1.3 倍は人間に不可能な速度ではないので、確定の証拠にはならない。
2 倍以上にすると一目で異常と分かり、疑念ではなく確信になってしまう。

### 2-4. 止まっている相手に近づかれたら

プレイヤーが振り向いたまま**歩み寄ってくる**場合（正面から接近される）、ドッペルは背後を取れない。

| プレイヤーとの距離 | ドッペルの行動 |
|---|---|
| 4m 以上 | 止まったまま |
| 4m 未満 | **背を向けて歩き去る。**「待っていた仲間が、先に行くね、と歩き出した」ように見える |

歩き去るドッペルの**背中が、今度はプレイヤーに向く**。
つまり、疑って近づけば、**掴む機会が生まれる。**恐怖に主体性を返す。

追いかけて掴めば撃退。追いかけずに見送れば、それは仲間だったかもしれない。

### 2-5. 全部の視線で止まるわけではない

**常に止まると、規則として学習され、「見れば止まる」が安全確認になってしまう。**
疑念を保つために、止まらない場合を混ぜる。

| 段階（FUN_CORE 4-7） | 見られたときの行動 |
|---|---|
| 疑念（1:00〜4:00） | **70% は止まらず、仲間のように普通に歩き続ける。**30% で止まる |
| 狩り（4:00〜） | **接近中は 100% 止まる。**襲撃・追跡中は止まらない（走って追う） |

疑念の段階で「時々止まる魚」を見た記憶が、狩りの段階で「必ず止まる魚」を見たときに繋がる。
**最初から 100% 止まると、ただのギミックになる。**

### 2-6. 仲間 AI も、時々止まる

「ひとりで試す」モードの仲間 AI は、**プレイヤーに見られたとき 20% の確率で 1〜3 秒止まる。**
そうしないと、ソロモードでは「止まる＝敵」が確定してしまい、2-5 の設計が崩れる。

人間の仲間は自然に止まる（待つ、迷う、確認する）ので、マルチではこの処理は不要。

### 2-7. 複数人での挙動 — ここが協力になる

視界判定は**全員の視界の和**。

- A が振り返ってドッペルを視界に入れる → 止まる
- ドッペルの標的は B（A を見ていない）だが、**A の視線で止まっている**
- A は「見てるから、走れ」と言える。**視線で敵を釘付けにする役割**が生まれる
- その間に C が背後から回り込んで掴む

**「見る人」「逃げる人」「掴む人」の 3 役が、追加ルールなしで発生する。**
これが本作の協力の形になりうる。

止まっているドッペルは**通常どおり背後から掴める**。止まっている間は動かないので、
回り込みは容易。ただし A が視線を外した瞬間に動き出す。

### 2-8. 現行 AI との関係

現行の「視界コスト付きナビゲーション」（見られないように回り込む）は、
**「見られていない間の経路選択」として残す。**
見られていない → 視界を避ける経路で 1.3 倍で接近。
見られた → 止まる。
現行の「振り返られたら襲撃を中断する」は、そのまま「止まる」の一部になる。

賢く回り込む AI は、賢いが**見えないので怖くない**。
止まる AI は、単純だが**見えるので怖い**。両方を持たせる。

## 3. 距離定数の再調整 — 速度を変えたら必ずやること

**現行の全ての距離は 4.4 m/s を前提に調整されている。**速度だけ変えると全部狂う。

距離を 2 種類に分ける。

### 3-1. 物理的な距離 — 変えない

体の大きさや腕の長さで決まるもの。速度と無関係。

| 項目 | 現行値 | 扱い |
|---|---|---|
| 掴みの射程 | 1.5m / 2.1m | **そのまま** |
| プレイヤー半径 | 0.34m | そのまま |
| 名札が読める距離 | 2m | そのまま |
| 壁の鏡が映す距離 | 2.8m | そのまま（または少し広げる） |

### 3-2. 反応時間で決まる距離 — 速度比で縮める

「気づいてから届くまでの秒数」で決まっているもの。
係数 **1.6 / 4.4 ≈ 0.36** を掛けてから、プレイテストで再調整する。

| 項目 | 現行値 | 換算 | 備考 |
|---|---|---|---|
| 走りの伝染半径 | （新規） | **10m** | 走り 3.2 m/s で約 3 秒。呪われた人に追いつける距離 |
| 出現の最小距離 | 11m | **6m** | 歩き 1.6 m/s で約 4 秒。見えない場所という条件は維持 |
| 出現の推奨最大距離 | 26m | **12m** | |
| ワープ先の距離帯 | 4〜14m | **2.5〜7m** | 経路長 24m → 10m |
| 天井落下の着地距離 | 5〜7m | **3〜4.5m** | 歩きで 2〜3 秒先 |
| 天井落下の発生条件（他者の距離） | 12m | **6m** | |
| 襲撃後の目撃判定距離 | 8m | **5m** | |
| ドッペルの遭遇記憶の距離 | 5m | **4m** | |
| 札の配置間隔・祠からの距離 | 10m 超 | **6m 超** | または札の枚数を半分に（FUN_CORE 3-3） |

### 3-3. 時間で決まるもの — 変えない

| 項目 | 扱い |
|---|---|
| 被掴み演出 1.2 / 1.5 / 3.0 秒 | そのまま |
| 掴みの予備動作 0.2 / 0.35 秒 | そのまま |
| クールダウン 8 秒 | そのまま |
| 試合時間 6 分 | そのまま。ただし**マップの広さと札の枚数を歩きに合わせる**（3-4） |

### 3-4. マップの広さ

94m 四方は、走りなら 21 秒で横断、歩きなら約 60 秒。

6 分の試合で 60 秒の横断は**やや広い**。選択肢：

| 案 | 内容 |
|---|---|
| A | マップを **70m 四方**程度に縮める。密度が上がり、遭遇が増える |
| B | 94m のまま、**札を半分**にし、開始位置を中央寄りにする |
| C | 94m のまま、**使う区画を試合ごとに変える**（一部を閉鎖）。部分ランダム化にもなる |

**C を推奨。**マップを作り直さず、密度を上げ、リプレイ性の対策（AI_DESIGN 6-9）を兼ねる。

## 4. 「サクサク」を保つための条件

歩きにすると「もっさり」に転びやすい。以下を守る。

| 項目 | 条件 |
|---|---|
| 加速・減速 | **なし。**入力した瞬間に 1.6 m/s、離した瞬間に 0 |
| 入力から画面反応 | 100ms 以下（クライアント予測） |
| 旋回 | 2.2 rad/s。もたつくなら 2.6 まで上げる。3.0 を超えると背後の緊張が消える |
| 次の目標までの距離 | **10 秒（16m）以内に必ず何かがある**ようにマップを組む |
| 停止時間 | 被掴み以外で操作を奪わない |
| 走りの発動 | 状態変化で**即座**。「走り出した」が一瞬で分かる |

「サクサク」は速度ではなく、**入力への即応と、待ち時間のなさ**で決まる。
歩きでも、押した瞬間に動き、離した瞬間に止まり、常に 10 秒以内に目的があれば、もたつかない。

## 5. トーンの変化について（確認）

常時走りの魚頭マッチョは、コメディ寄りだった。歩きにすると**ホラー寄りに動く。**

これは損失ではない。

- コメディは**見た目**（魚頭・上半身裸）に残る
- ホラーは**挙動**（歩く、止まる、走り出す）から来る
- **走りが「パニック」の作画になる**ことで、コメディの走りが恐怖の走りに変わる。
  常時走りでは、この転換が起きなかった

Lethal Company の構造と同じ。見た目はふざけていて、状況は本気で怖い。
