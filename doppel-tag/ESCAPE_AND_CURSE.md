# 脱出ゲーム化・扉・呪いの伝染 — 仕様と相互作用

制作者の変更：**廃墟探索の脱出ゲーム化、扉の追加、呼び声の搭載、
呪われた人の近くにいると仲間まで呪われる（強制的に離れる）。**

LOCOMOTION.md（歩行・見られると止まる）と FUN_CORE.md（核モード）を前提にする。

---

## 1. 呪いの伝染 — 最初に解くべき矛盾

### 1-1. 矛盾

核の救助メカニクスは「**呪われた本人は掴めない → 仲間がドッペルの背後を取って撃退する**」。
撃退には掴みの射程 1.5m まで近づく必要がある。追跡中のドッペルは呪われた本人の至近にいる。

**近づいた瞬間に呪われるなら、誰も救助できない。**
救助が消えると、呪い＝実質の死になり、協力の中心が消える。

伝染そのものは良い。「来るな！」と叫ぶ場面、囮として離れる役割、
集団を強制的に割る圧力——どれも本作に欲しかったもの。
**必要なのは、救助が「不可能」ではなく「一瞬の賭け」になる調整。**

### 1-2. 解：伝染は「時間」で起きる

| 項目 | 値 |
|---|---|
| 伝染の発生源 | **呪われたプレイヤー**（ドッペルではない。ドッペルは掴みでしか呪わない） |
| 半径 | 3.0m |
| **必要な滞在時間** | **3.0 秒（連続）** |
| 遮蔽 | 壁・閉じた扉越しには伝染しない（視線判定と同じ） |
| 離れたとき | 蓄積は 1 秒で 0 に戻る（出入りを繰り返しても溜まらない） |

**3 秒あれば、決断した救助者は間に合う。**
歩き寄る（1.6 m/s、または伝染パニックの走り 3.2 m/s）→ 予備動作 0.2 秒 → 成立 → 離れる。
ためらえば呪われる。**救助が「行けるか？」という賭けになる。**

救助者の画面では、半径に入った瞬間から**画面の縁が黒く侵食**し、3 秒で全面に達する。
残り時間が体感で分かり、「あと 1 秒」の判断ができる。

### 1-3. 伝染した人は何になるか

現行の `cursed` は「今追われている」状態。伝染で 2 人目が呪われると、
1 体のドッペルは片方しか追えない。意味を分ける。

| 状態 | 内容 |
|---|---|
| **呪い（cursed）** | ドッペル D に印を付けられた状態。**掴めない。自動で走る。伝染源になる。**掴みで付くか、伝染で付く |
| **追跡対象（target）** | D が今追っている 1 人。呪われた人の中から D が選ぶ |
| 累積被掴み（hits） | **掴みでのみ増える。伝染では増えない** |

伝染は殺さない。**救助能力を奪う。**
呪われた人が増えるほど、掴める人が減り、残った 1 人が貴重になる。
全員が呪われれば誰も掴めず、消耗で負ける。**だから離れなければならない。**

### 1-4. 呪いの解け方 — 2 つの道

現行は「撃退されたときだけ解除」。伝染を入れるなら、もう 1 つの道が要る。
そうでないと全員呪われた時点で詰む。

| 道 | 条件 | 意味 |
|---|---|---|
| **救助** | D が背後から掴まれて撃退される | D に呪われた**全員**が同時に解ける |
| **振り切り** | **D が 10m 以内にいない状態が 20 秒続く** | **本人だけ**解ける |

**振り切りが、呪われた人の目標になる。**
「離れろ」と言われて離れた人が、ただ待つのではなく、**一人でドッペルを撒く**という
明確な仕事を持つ。扉（2 章）がその道具になる。

呪われた本人が離れるほど、仲間は安全で、本人は振り切りに近づく。
**「離れる」が犠牲ではなく、正解になる。**

### 1-5. 伝染の悪用と誤爆

パニックした（あるいは意地悪な）呪われた人が仲間に突っ込んでくる場合。

- 3 秒の猶予があるので、仲間は離れられる
- 呪われた本人の画面に**自分の伝染半径を常時表示**する（赤い円）。無自覚の誤爆を防ぐ
- 仲間の画面には、呪われた人が 6m 以内に入った時点で**警告音と方向**を出す
- 意図的な妨害は仕様では防げない。身内前提なら許容。野良なら通報の対象

なお、**叫びながら突っ込んでくる仲間**は、本作で最も怖い光景の一つになる。
仕様で潰す必要はない。

## 2. 扉

歩行速度の世界では、**扉が唯一の逃走手段**になる。速度差では逃げられないので、
遮蔽と時間稼ぎで逃げる。

### 2-1. 基本

| 項目 | 値 |
|---|---|
| 開閉 | 調べるボタン。**開けるのに 0.6 秒、閉めるのに 0.3 秒**。その間は停止 |
| 誰が開けられるか | 全員。ドッペルも同じ速度で開ける（擬態を守る） |
| 音 | 開閉音は **15m** まで届く。壁越しはこもる。**マップで最も遠くまで届く音**にする |
| 視線 | 閉じた扉は視線を遮る |
| 伝染 | 閉じた扉は伝染を遮る |
| 状態 | 開・閉の 2 状態。半開きなし。施錠は脱出の扉のみ（3 章） |

### 2-2. 扉が生む状況

**逃げる側：**閉めるのに 0.3 秒、追う側が開けるのに 0.6 秒。**扉 1 枚で約 0.9 秒稼ぐ。**
歩きで約 1.5m。扉を 3 枚抜ければ視界から消える。
1-4 の振り切り（10m・20 秒）は、扉を使わなければ達成できない設計にする。

**追われていない側：**閉じた扉の向こうが見えない。開けるまで何がいるか分からない。
開けた先に、こちらを向いた魚が立っている。仲間か、それとも。

**音：**自分が閉めた扉が、後ろで開く音。**古典だが、これが効く。**
歩きで足音が静かになったぶん、扉の音が際立つ。

### 2-3. 扉と「見られると止まる」の相互作用

止まっているドッペルの前で扉を閉める → 視線が切れる → **動き出す。**

プレイヤーは学習する：「釘付けにしている間は、視線を切るな」。
LOCOMOTION 2-7 の「見る人・逃げる人・掴む人」に、**扉を閉める役**が加わる。
掴んだ直後に扉を閉めて撤退する、という連携が生まれる。

### 2-4. 扉と歩き去るドッペル

LOCOMOTION 2-4：近づかれたドッペルは背を向けて歩き去る。
**歩き去った先で扉を閉める。**
追って開けると、その先にいるか、いないか。
いない場合、それは本当に仲間だったのかもしれない。

## 3. 脱出

お札と祠の収集を、**脱出**に置き換える。

### 3-1. 目標は小さく

| 項目 | 値 |
|---|---|
| 必要なもの | **鍵 2〜3 個**（人数で変える。3 人 2 個、6 人 3 個）。お札 30 枚の再来にしない |
| 鍵の場所 | 施錠された部屋の奥。**開始地点と出口から遠く、互いにも離れた**位置 |
| 出口 | 1 か所。全部の鍵が揃うと開けられる |
| 時間 | 6 分は維持。時間切れは全員敗北 |

鍵は持ち運ぶ。持っている人が脱落すれば床に落ちる。**鍵を持っている人が呪われたら**、
その人に近づけない——鍵を拾うには 3 秒以内に離れる必要がある。

### 3-2. 出口の扉 — 本作の感情的な頂点

**Left 4 Dead 方式**を採る。

| 段階 | 内容 |
|---|---|
| 解錠 | 鍵が揃った状態で調べる。**3 秒**かかる |
| 開放 | 開く。**15 秒間**開いたまま |
| 脱出 | 開いている間に出た人が脱出。**閉じた時点で残った人は取り残される** |
| 終了 | 全員が脱出または脱落、あるいは 15 秒経過で試合終了。脱出者は勝ち、取り残された人は負け |

**15 秒の間に、呪われた仲間が出口へ走ってくる。**
出口の前に集まっている仲間の 3m 以内に、その人が入れば伝染が始まる。

- 待てば、全員が呪われて出られなくなるかもしれない
- 閉めれば、その人を置いていく
- **呪われた本人は、来るべきか、来ないべきか**

この 15 秒のために、他の全てがある。
「みんなで脱出」と「置いていく」の間の判断が、協力ゲームの最も強い記憶になる。

### 3-3. 全員脱出の条件（任意）

全員で脱出できた場合だけ、追加の報酬や称号を出す。
「誰か置いてきた」勝利と「全員で出た」勝利を、結果画面で明確に区別する。
置いていく判断を罰しないが、全員で出る価値は示す。

## 4. 呼び声

「呼び声搭載」が以下のどれを指すか、確認が要る。それぞれ設計上の意味が違う。

### 4-1. 近接ボイスチャットのこと

FUN_CORE 5-5 で強く推奨した内容。実装済みなら最良。

- 伝染と組み合わさると、**「来るな！」「助けて！」が実際の声になる**
- 出口の 15 秒で、呪われた人の声が近づいてくる
- 距離減衰と壁越しのこもりは必須。**閉じた扉越しは、こもるが聞こえる**ようにする。
  扉の向こうの声が仲間の声だとしても、開けるかどうかは別問題

### 4-2. 呼びかけボタン（R）のこと

自分の魚の名前を叫ぶ、位置を知らせるピン。

- **ドッペルも使える**（擬態）。ただし**直近に聞いた呼びかけを 0.5〜1.5 秒遅れて返す**だけ。
  能動的には呼ばない
- 呪われた人が呼ぶと、**「近づくな」の意味を持つ別の音**にする（自動切替）
- 確定手段にはしない。位置と、疑念の材料

### 4-3. ドッペルが呼ぶこと

**最も強いが、最も慎重に扱う機能。**

- ドッペルが、**コピー元の声で、別のプレイヤーの名前を呼ぶ**
  （近接 VC があれば、直近 10 秒の録音を歪めて再生。AI_DESIGN 3-4）
- 暗い部屋の奥から「フグ、こっち」と、マグロの声
- **本物のマグロは、別の場所にいる**

呼ばれた側は行くか行かないか。行けば背後を取られる。行かなければ本物だったかもしれない。
伝染と組み合わせると、**「助けて」という呪われた仲間の声も、罠かもしれない**。

制限：**1 試合に 1〜2 回。狩りの段階のみ。**乱発すると「声は全部偽物」と学習されて死ぬ。

### どれであっても

**呼び声は確定手段にしない。**確定できる手段は「背後から掴む」だけ。
声は疑念を増やすためのものであって、減らすためのものではない。

## 5. 相互作用の一覧

新旧の仕組みがぶつからないかを表にする。**実装前に GPT6 と確認すること。**

| 組み合わせ | 期待する挙動 |
|---|---|
| 伝染 × 救助 | 3 秒以内に掴んで離れれば呪われない。掴みが成立すれば全員の呪いが解け、伝染も止まる |
| 伝染 × パニック走り（LOCOMOTION 1-3） | 10m 以内で走り出す。3m・3 秒で呪われる。**走りは「逃げる」にも「一瞬で救助する」にも使える** |
| 伝染 × 扉 | 閉じた扉越しには伝染しない。呪われた人が部屋に籠れば、仲間は扉の外で安全 |
| 伝染 × 出口 | 出口前の集団に呪われた人が来ると伝染が始まる。3-2 の判断 |
| 伝染 × 鍵 | 呪われた人が持つ鍵は、その人が離れるか脱落するまで実質取れない。**呪われた人は鍵を床に置ける**ようにする（調べるボタン長押し） |
| 振り切り × 扉 | 扉なしで 20 秒間 10m を保つのは歩きでは不可能に近い。扉 3 枚で達成できる設計 |
| 振り切り × 見られると止まる | **追跡対象自身の視線ではドッペルは止まらない**（LOCOMOTION 2-5 のとおり）。止めるのは他人の視線だけ |
| 第三者の視線 × 追跡中 | 追跡中のドッペルを他人の視線で止められるのは **6m 以内**から。遠くから見ているだけで止められると、追跡が成立しない。近づく＝伝染の危険を負う |
| 扉 × 見られると止まる | 視線を切ると動き出す。釘付け中に扉を閉めない |
| 呼び声 × 伝染 | 呪われた仲間の「助けて」に行けば、伝染の危険。行かなければ見捨てる |
| 仲間 AI（ソロ） | 呪われた人から離れる。ただし**3 秒以内の救助を試みる**判断を持つ。伝染半径を知っている |
| 脱落者ドッペル × 伝染 | 脱落者由来のドッペルも掴みで呪う。伝染源にはならない（ドッペルは伝染しない） |

## 6. 削除・置換の確認

| 旧 | 新 |
|---|---|
| お札・祠・保管数 | **削除。**鍵と出口に置換 |
| 「撃退のみで呪い解除」 | 撃退 **または** 振り切り（1-4） |
| 救援ブースト 1.15 倍 | パニック走り（LOCOMOTION 1-3）に統合済み |
| 水分（核モードで無効） | 引き続き無効。脱出ゲームに分散の圧力は**伝染**が与えるので、資源で分散させる必要がなくなった |

**伝染が入ったことで、水分・電池による分散の強制は不要になる。**
「離れなければならない理由」を、資源ではなく恐怖で作れている。
これは前の設計より良い。

## 8. 受け入れ確認

| シナリオ | 期待する結果 |
|---|---|
| 呪われた仲間の 3m 以内に 2.5 秒いて離れる | 呪われない。蓄積は 1 秒で消える |
| 3m 以内に 3 秒 | 呪われる。掴めなくなり、走り出す。hits は増えない |
| 2.5 秒でドッペルを掴んで撃退 | 自分は呪われず、仲間の呪いも解ける |
| 壁・閉じた扉越しに 3m 以内 | 伝染しない |
| 呪われた人が扉 3 枚を閉めて 20 秒逃げる | 呪いが解ける。ドッペルは追跡対象を失う |
| 呪われた本人がドッペルを見る | **止まらない**（追跡対象の視線は無効） |
| 8m 離れた仲間がドッペルを見る | 追跡中は**止まらない**。6m 以内なら止まる |
| 釘付け中に扉を閉める | ドッペルが動き出す |
| 鍵を持ったまま呪われる | 調べる長押しで鍵を床に置ける |
| 鍵 3 個で出口を調べる | 3 秒で解錠、15 秒開く。閉じた時点で残った人は取り残される |
| 出口前で呪われた仲間が 3m 以内に来る | 伝染が始まり、画面の縁が侵食する |
| 呪われた人の呼びかけ | 通常と別の「近づくな」の音になる |
| ドッペルの呼びかけ | 直近の呼びかけを遅れて返すだけ。能動的な呼びは 1 試合 2 回まで |
| 全員が呪われる | 誰も掴めない。振り切りだけが解除手段になる。詰まない |
