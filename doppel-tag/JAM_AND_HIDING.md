# ジャムと隠れ場所 — 1 階の「やり過ごす」仕様

制作者の指示（2026-09-17）を仕様に起こしたもの。

> 2 階で地下の鍵を取ったら、1 階に無敵の敵（包丁を持った、血まみれの、ジャムおじさんのような見た目。名前は**ジャム**）が現れ、隠れてやり過ごすしかない。

用語：本書では敵を **ジャム**、隠れる家具を **隠れ場所**（ロッカー・段ボール箱）と呼ぶ。
ゲーム内の表記も「ジャム」。内部 ID は `jam`。

前提：脱出モードの 4 階層（1階・2階・地下・地上）と、ESCAPE_FEEDBACK_2026-09-17.md の変更。

---

## 0. 何が変わるか（要点）

| 項目 | 内容 |
|---|---|
| 出現 | **2 階で地下の鍵を手に入れた瞬間**（暗号錠を開けた瞬間）、**1 階に**ジャムが 1 体出現。試合終了まで消えない |
| 性質 | **掴めない。撃退できない。**倒す手段は無い。速度はドッペルの **1.1 倍** |
| 対処 | 1 階に最初から置いてある**隠れ場所**（ロッカー 1 つ、段ボール箱 人数 − 1 個）に入ってやり過ごす |
| 隠れ方 | 「調べる」で入る。専用画面（視点を動かす・出る、だけ）。ロッカーは広く見渡せ、箱は穴が小さく視点が低い |
| 見つかる条件 | 隠れている間は**誰にも見つからない**。ただし**入るところを見られたら**引きずり出される。ライトを消せば見られていても入れるが、**2 m 以内に敵がいると入れない** |
| 攻撃 | 包丁を振り下ろす演出、斬撃、画面に血が飛び散る |

ジャムは「背後を取り合う」相手ではない。**1 階だけ、ルールが変わる**：掴みではなく、隠れる・やり過ごす・通り抜ける。
2 階で鍵を取った後、地下の鍵扉（1 階）まで戻る道が、この試合で最も怖い区間になる。

## 1. ジャム

### 1-1. 見た目

| 項目 | 内容 |
|---|---|
| 体格 | 探索者より頭一つ高い（**2.1 m**。探索者は 1.8 m）。太い |
| 服 | 白いコック服と前掛け。**前掛けと袖が血で染まっている**。血は乾いた茶色と新しい赤の 2 層 |
| 顔 | 丸く大きい。目が小さく、口角が上がったまま。**魚頭ではない**（この施設にいる唯一の人間の顔） |
| 持ち物 | 右手に肉切り包丁（刃渡り 40 cm）。歩くと刃が壁や床に当たって**金属音**が鳴る |
| 作画 | 8 方向 × 走り 4 コマ、8 方向 × 待機 1 コマ、正面 × 攻撃 3 コマ（振り上げ・振り下ろし・戻し）、正面 × 探す 2 コマ（左右を見る） |
| 光 | 自分では光らない。**探索者のライトに照らされたときだけ見える。**暗闇では足音と金属音だけ |

ジャムの立ち姿は**遠くからでも輪郭で分かる**ようにする（頭が丸く、肩が広い、包丁が突き出る）。ドッペルとの見間違いは起こさない。

### 1-2. 出現

| 項目 | 値 |
|---|---|
| 条件 | `progress.key` が 1 になった瞬間（2 階の暗号錠が開き、地下の鍵を得た瞬間） |
| 場所 | **1 階の中央交差点**（12,12）。誰もいなければそこ、誰かがいれば 1 階の中で**全員から 15 m 以上離れた**通路 |
| 演出 | 全階で聞こえる音：**厨房の扉が蹴り開けられる音**（1 階が発生源。2 階・地下では「下の階から」「上の階から」の方向矢印つき）。1 階にいる人には床が震える振動と、遠くで包丁が壁を擦る音 |
| 通知 | 「1 階に何かがいる。隠れ場所を探せ。」を 5 秒。任務リストに「1 階のジャムをやり過ごして地下へ」が追加される |
| 手引き | 2 階の暗号錠の前に、**「鍵を取ると 1 階に何かが来る」**と読めるメモ（既存のメモとは別の、背景としての落書き）。初見殺しにしない |

### 1-3. 移動と行動

| 項目 | 値 |
|---|---|
| 速度 | ドッペルの 1.1 倍：**2.66 m/s**（探索者は点灯 2.3、消灯 1.61）。**走って逃げ切ることはできない** |
| 行動範囲 | **1 階のみ。**階段・梯子・地下への入口には入らない。追跡対象が階を移ると、入口の前で 3 秒立ち止まり、巡回に戻る |
| 巡回 | 1 階の環状通路を回る。**地下の鍵扉（21,20）の前を必ず通る**経路にする。周回ごとに向きをランダムに反転 |
| 視覚 | 前方 **90°**、距離は相手が**点灯なら 14 m、消灯なら 6 m**。遮蔽物・閉じた扉越しには見えない |
| 聴覚 | **点灯して走る**探索者の足音を **8 m** 以内で聞く。消灯の忍び歩きは聞こえない |
| 発見 | 見るか聞くと **追跡**。追跡中は最短経路で向かう（探索者の視界コストを無視。**ジャムは隠れて近づかない**） |
| 見失い | 対象を **4 秒**見失うと、最後に見た地点へ行き、**6 秒**その場で左右を見る（探す 2 コマ）。見つからなければ巡回へ |
| 隠れ場所 | **開けない。**隠れている探索者を認識しない（3 章）。ただし 3-4 の「入るところを見られた」場合だけ引きずり出す |
| ドッペルとの関係 | 互いに干渉しない。ドッペルもジャムに襲われない。同じ通路にいても両方が探索者を狙う |
| 掴み | **掴めない。**掴みボタンの対象にならない（`grabAvailable` が立たない）。掴もうとしても「手が届かない」ではなく、ボタン自体が出ない |
| 天井落下・ワープ・変身 | 使わない。ジャムは常に歩いて来る |

### 1-4. 攻撃

| 段階 | 時間 | 内容 |
|---|---|---|
| 接近 | — | 1.4 m 以内、かつ相手が前方 120° にいる |
| 振り上げ | **0.5 秒** | 包丁を頭上に。金属音。**この間に 1.4 m の外へ出れば空振り**（歩きで 1.15 m、ぎりぎり届かない距離設計） |
| 振り下ろし | 0.15 秒 | 当たり判定 |
| 命中 | — | 相手：`hits` **+1**（ドッペルの掴みと同じ 3 回で脱落）。**0.8 秒**よろける（移動不可）。画面に斬撃線 1 本と血しぶき（2 章）。呪い状態には**しない**（ジャムは撃退できないので、呪いを付けると解除手段が無い） |
| 空振り | — | 包丁が床か壁に当たる。火花と大きな金属音。**1.0 秒**硬直 |
| 戻し | **2.5 秒** | 命中後、包丁を前掛けで拭う。**この間は追わない。**逃げる・隠れる時間 |

命中 3 回目は脱落。演出は「振り下ろし → 暗転 → 血が画面全体に広がる」。ドッペルの顔アップは使わない（ジャムに正体の嘘は無い）。

**逃げ方の設計**：速度で勝てないので、命中後の 2.5 秒と、空振りの 1.0 秒が、**隠れ場所に入るための時間**。
隠れ場所までの距離が 2.5 秒 × 2.3 m/s ≒ 5.7 m 以内なら間に合う。**隠れ場所は 1 階の通路 12 m ごとに 1 つ**置く（4 章）。

### 1-5. 消えない

- 撃退・清めの石・時間経過で消えない。試合終了まで 1 階を巡回する
- 探索者が全員 1 階から出ても巡回を続ける（地下から戻ってくる人のため）
- 脱落者由来のドッペルが 1 階に出ても、ジャムはそのまま

## 2. 攻撃の演出

| 要素 | 内容 |
|---|---|
| 振り上げ | ジャムの正面スプライトを攻撃 1 コマ目に。包丁が画面上端まで届く大きさ |
| 振り下ろし | 攻撃 2 コマ目。同時に**画面を斜めに横切る白い斬撃線**（右上 → 左下、0.1 秒で描いて 0.3 秒で消える） |
| 血しぶき | 命中の瞬間、画面の縁から中央へ**赤い飛沫を 12〜20 滴**。0.2 秒で広がり、**3 秒**かけて垂れて薄くなる。滴の位置は毎回ランダム |
| 揺れ | 画面を 0.3 秒、振幅 12 px で揺らす |
| 音 | 振り上げ：包丁が空気を切る音。命中：肉を断つ音＋短い悲鳴（本人の魚の声）。空振り：金属が石を叩く音 |
| 3 回目 | 振り下ろしの直後に**暗転**。血が画面下から上へ 1.5 秒で広がる。「Game Over　{名前}は、包丁の前に倒れた…」 |
| 第三者 | 近くの仲間の画面には、ジャムが振り下ろす動作と、相手がよろける動作が見える。血しぶきは本人だけ |
| 明滅軽減 | 設定が ON なら血しぶきの量を 1/3、揺れ無し、斬撃線は細く。暗転はそのまま |

## 3. 隠れる

### 3-1. 隠れ場所の種類

| | ロッカー | 段ボール箱 |
|---|---|---|
| 数 | **1 階に 1 つ** | **AI を含む人数 − 1 個**（3 人なら 2、6 人なら 5） |
| 見た目 | 鉄製、灰緑色、高さ 2 m。扉に**縦の通気スリット** | 段ボール、高さ 1.1 m、口が閉じている。側面に**握りこぶし大の穴** |
| 入る動作 | 扉を開け、後ろ向きに入り、扉を引く。**0.6 秒** | しゃがんで潜り込み、口を閉じる。**0.6 秒** |
| 視点の高さ | **1.5 m**（立った目線） | **0.5 m**（床すれすれ） |
| 視野 | スリット越し。**横 70°・縦 30°**。首は左右 ±50°、上下 ±15° | 穴越し。**横 35°・縦 20°**。首は左右 ±25°、上下 ±10°。画面の縁が暗い |
| 定員 | 1 人 | 1 人 |
| 出る動作 | 0.5 秒 | 0.5 秒 |
| 音 | 入るとき金属の扉音（**8 m** に届く） | 入るとき段ボールの擦れる音（**3 m**） |

合計は**人数と同じ**（ロッカー 1 ＋ 箱 人数 − 1）。全員分あるが、**近くに空いている保証は無い**。AI の仲間も使う。

### 3-2. 配置（1 階、試合開始時から置く）

ジャムが出る前から置いておく。序盤は「なぜこんな所に箱が」という違和感だけが残る。

| 場所（マス） | 種類 | 理由 |
|---|---|---|
| (10,18) 受付の脇 | **ロッカー** | 開始地点の近く。最初に見つかる。見渡せるので「ここに戻ればいい」と覚える |
| (12,7) 北の廊下、梯子の手前 | 箱 | 2 階から降りてすぐ |
| (5,12) 西の交差点 | 箱 | 西回りの中継 |
| (19,12) 東の交差点 | 箱 | 東回りの中継 |
| (17,19) 鍵扉の手前 | 箱 | **鍵扉の作業（1 秒）の直前**に逃げ込める |
| (8,20) 南西の角 | 箱 | 人数 6 のときだけ |

人数が少ないときは表の上から順に置く（3 人：ロッカー＋(12,7)＋(5,12)）。
どの隠れ場所からも、**次の隠れ場所まで歩きで 5〜6 秒**（12〜14 m）以内にする。1-4 の「命中後 2.5 秒＋硬直」で間に合う距離。

### 3-3. 入る

| 項目 | 内容 |
|---|---|
| 操作 | 隠れ場所の **1.5 m 以内**で、隠れ場所の方を向き、**「調べる」**（PC は F、スマホは兼用ボタン）。案内は「ロッカーに隠れる」「箱に隠れる」 |
| 空いていない | 「誰かが入っている」と表示。入れない |
| 呪い中 | **入れる。**入ると追っていたドッペルは対象を失い、隠れて **20 秒**で呪いが解ける（ESCAPE_AND_CURSE の「振り切り」を隠れ場所で達成できる） |
| 二次呪い中 | 入れる |
| 作業中・演出中・鏡中 | 入れない |
| ライト | 入った時点で自動的に消える。出たときは**消えたまま** |
| 持ち物 | そのまま（鍵・バールは持って入れる） |

### 3-4. 入るところを見られる

**入る動作の 0.6 秒の間に、敵（ドッペルまたはジャム）の視界に入っていたら「見られた」。**

| 状況 | 結果 |
|---|---|
| **ライト点灯**で入り、敵の視界内（1-3 の視覚条件、ドッペルは `sees()`） | **見られた。**入り終えた直後に敵がやって来て、扉／箱を開け、引きずり出す（1.0 秒）。ドッペルなら**掴み成立（呪い）**、ジャムなら**斬撃（hits +1）**。引きずり出された隠れ場所は **10 秒**使えない |
| **ライト消灯**で入り、敵の視界内 | **見られない。**忍び歩きは暗いので気づかれない扱い |
| ライト消灯、敵が **2 m 以内** | **入れない。**案内が「近すぎる」に変わり、調べるが効かない。離れるか、点灯して賭けるしかない |
| 敵の視界外（遮蔽・後ろ向き・距離外） | 見られない |

「ライトを消せば入れる。ただし敵の目の前では無理」。
**消灯 → 2 m より外で → 入る**が正解手順で、それを覚える過程がこの区間の学習になる。

### 3-5. 隠れている間

| 項目 | 内容 |
|---|---|
| 画面 | **専用画面**に切り替わる。3D はロッカーのスリット／箱の穴から見える範囲だけ。HUD は最小限（残り時間・仲間の状態・「出る」ボタン） |
| 操作 | **視点の移動と「出る」だけ。**PC：マウスで視点、F または E で出る。スマホ：スワイプで視点、右下の大ボタン「出る」。移動・掴み・ライト・鏡・施設図は**無効** |
| 敵 | **ドッペルにもジャムにも見つからない。**敵の視覚・聴覚から除外。ジャムが目の前を通っても開けない |
| 伝染 | 隠れている間は**被曝しない・させない**（箱が遮蔽物） |
| 音 | 自分の心音（敵が 6 m 以内で速くなる）、外の足音と金属音はこもって聞こえる。**ジャムが 2 m 以内にいると呼吸音が入る**（怖さの本体） |
| 時間 | 試合時間は進む。隠れ続ければ時間切れ |
| 仲間 | 仲間の画面では、入っている隠れ場所が**わずかに揺れる**（誰かいる、と分かる程度）。名前は出ない |
| 会話 | 呼び声（R）は使えない |

### 3-6. 出る

- 「出る」で 0.5 秒かけて出る。出た瞬間の位置は隠れ場所の**正面 0.8 m**、向きは隠れ場所に背を向けた向き
- 出る動作は**取り消せない**。出た先に敵がいれば、そのまま襲われる（覗いてから出るのが正解）
- 出るときの音は入るときと同じ距離に届く

### 3-7. AI の仲間

- ジャムを **12 m 以内**で見るか聞くと、**最寄りの空いている隠れ場所へ**消灯して向かい、入る。2 m 以内に敵がいれば入らずに離れる
- ジャムが **20 m 以上**離れるか、30 秒経つと出る
- 隠れ場所が全部埋まっていれば、ジャムから最も遠い通路へ逃げる
- 人間が入ろうとしている隠れ場所は取らない（1.5 m 以内に人間がいれば譲る）

## 4. 1 階の流れ（この仕様が作る体験）

```
2 階で暗号錠を開ける → 全階に扉を蹴り開ける音 → 「1 階に何かがいる」
  ↓
梯子で 1 階へ。ライトを消して降りる。金属音が近づいたり遠ざかったりする
  ↓
鍵扉（21,20）まで、隠れ場所を伝って進む（(12,7) → (19,12) → (17,19)）
  ↓
鍵扉の前で 1 秒の作業。金属音が近い。箱に入って待つか、賭けるか
  ↓
地下へ降りる。ジャムは入口の前で 3 秒立ち止まり、戻っていく
```

- ジャムを見たことがない人は、金属音だけで想像する。**見えないのが一番怖い**ので、1 階は暗いまま
- ドッペルは 1 階にもいる。**隠れ場所に入るところをドッペルに見られる**方が、ジャムに見られるより起きやすい
- 隠れ場所は 1 人用なので、6 人が同時に来ると 2 人はあぶれる。**先に入った人が「今来るな」と言う**場面ができる（ボイスチャットがあれば）

## 7. 受け入れ確認

| シナリオ | 期待する結果 |
|---|---|
| 2 階で暗号錠を開ける | 全階で扉の音。1 階の中央にジャムが出る。任務リストに 1 行増える |
